# สรุปงาน: เซียมซีต่อท้ายใบเสร็จ Sea & Hill (POS Hero / pos-lan)

> อัปเดต 6 พ.ย. 2569 · เวอร์ชันล่าสุด **v1.9.1** · เอกสารนี้เขียนไว้ให้ session ถัดไป (เช่น VS Code ที่ร้าน) อ่านแล้วทำต่อได้เลย

## เป้าหมาย
ทุกบิลที่ Sea & Hill พิมพ์ ให้มีใบเซียมซีเจ้าแม่กวนอิมต่อท้าย **บนกระดาษแถบเดียวกัน** แล้วจึงตัด ไม่มีเงื่อนไขยอดเงิน

วิธี: ตั้งไดรเวอร์ EPSON TM-T82III เป็น **Paper Cut = No Cut** → POS Hero เฝ้าคิวเครื่องพิมพ์ เมื่อใบเสร็จพิมพ์จบจึงพิมพ์เซียมซีต่อ แล้วส่งคำสั่งตัดเอง (ใบเสร็จต้องถูกตัดเสมอ)

## ลอจิกการทำงาน (สั้นๆ)
1. watcher ส่ง `done` เมื่อ job หายจากคิว (พิมพ์จบ)
2. ข้ามงานชื่อ "POS Hero Receipt" (ของ POS Hero เอง ตัดในตัวอยู่แล้ว) และ job id ที่เคยทำแล้ว (จำ 200 รายการ)
3. ถ้า `enabled` และ ชื่อเอกสารตรง `docFilter` และอยู่ในช่วงวัน → พิมพ์เซียมซี (สุ่มด้วย `crypto.randomInt`) ซึ่งจบด้วย `ESC d 2` + `GS V 65 0`
4. ถ้าเซียมซีพลาด / ไม่ตรงเงื่อนไข → ส่ง `ESC d 2` + `GS V 65 0` อย่างเดียว (ใบเสร็จถูกตัดเสมอ)
5. เรนเดอร์ 100 ใบเก็บใน memory ล่วงหน้า (8 วินาทีหลังเปิดแอป เฉพาะเมื่อ `enabled` และ `slipEnabled`) พิมพ์จริงไม่มีความหน่วง
6. watcher เงียบเกิน 30 วินาที → แจ้งเตือน + รีสตาร์ทเอง; ตายเองก็รีสตาร์ทใน 2 วินาที
7. ทุกอย่างครอบ try/catch โมดูลพังต้องไม่ทำให้ POS Hero เดิมเปิดไม่ขึ้น (`require` ก็ครอบไว้)

## สิ่งที่ตรวจแล้วว่าไม่กระทบโค้ดเก่า
- ไบต์ใบเสร็จเดิมจาก `buildEscPosRaster` (เรียกแบบไม่ส่ง opts) เหมือนเวอร์ชัน 1.8.3 **ทุกไบต์** (ทดสอบ 5 ขนาดภาพ)
- `print:raw` ใช้ฟังก์ชันส่งกลางตัวใหม่ ลำดับเหมือนเดิม (เลือก default printer, ชื่องาน "POS Hero Receipt") ต่างแค่ชื่อไฟล์ชั่วคราวมีเลขสุ่ม
- ไม่ได้แตะโค้ดกระทบยอด ลิ้นชักเงิน relay renderer; `window-all-closed` ไม่ปิดแอป

## ⚠️ ความเสี่ยง / ที่ยังไม่รู้
- **งานพิมพ์ที่จบเร็วกว่ารอบเช็ก 250 ms** อาจถูกจับไม่ทัน → ใบเสร็จนั้นไม่ถูกตัด (เมื่อไดรเวอร์เป็น No Cut) ต้องวัดจริงในขั้น 0/ทดสอบ; ถ้าเจอ ให้ลดรอบเช็กใน `job-watcher.ps1` (`-IntervalMs`) หรือหาวิธีจับด้วยวิธีอื่น
- ถ้า POS Hero ปิด/ค้าง ขณะไดรเวอร์เป็น No Cut → ใบเสร็จไม่ถูกตัด ให้ติดวิธีตั้ง Paper Cut = Cut กลับไว้ที่เคาน์เตอร์
- ใบเซียมซีเต็ม (กลอนจีน + แปลไทย) ยาวราว 9–10 ซม. ใช้กระดาษเพิ่ม
- Windows ตัดคำไทยกลางคำได้ในบางบรรทัด (เช่น "ภาย/หลัง") — เป็นเรื่องรูปแบบ ยอมรับได้หรือเกลาข้อความ
- ความหมายไทยและคำแปลกลอน **เขียนโดย AI ทั้งหมด** ต้องให้คนอ่านจีนออกตรวจก่อนใช้จริง (โดยเฉพาะเรื่องสุขภาพ/เรื่องคู่)
- **ที่มาข้อมูลกลอน:** กลอน 100 ใบ + ระดับ มาจากแพ็กเกจ `qiantong` บน **PyPI** (ไม่ใช่ npm; แพ็กเกจ npm ชื่อเดียวกันว่างเปล่า) README ของมันระบุว่า **ข้อมูลกวนอิมไม่มี license** (เฉพาะโค้ดเป็น MIT) — ตัวกลอนเป็นของเก่าโบราณ แต่ถ้าไม่สบายใจเรื่องชุดข้อมูล ควรตรวจ/เปลี่ยนแหล่ง ตรวจเทียบใบ 61 และ 100 ตรงกัน, ระดับรวม 上 23 / 中 60 / 下 17

## ขั้นต่อไป (ทำที่ร้าน)
1. ติดตั้ง v1.9.1 (ปิดแล้วเปิดแอปให้อัปเดตเอง หรือรันตัวติดตั้งจาก Releases) ตรวจว่าเห็นปุ่ม 🥠 เซียมซี ในแผงปุ่มล่างและในเมนูถาด
2. **ขั้น 0:** เปิด "โหมดบันทึกอย่างเดียว" ขายจริง 3–5 บิล + พิมพ์ซ้ำ 1 ใบ + ปิดกะ 1 ครั้ง แล้วอ่าน `print-jobs.log` ดูชื่อเอกสารใบเสร็จ Sea & Hill เทียบกับงานอื่น และเวลาตั้งแต่เข้าคิวจนจบ
3. ตั้ง `docFilter` ให้ตรง, ตั้ง `printerName` (ชื่อใน Windows ของแต่ละสาขา), เลือกว่าจะคัดใบโชคร้ายออกไหม, ตั้งช่วงวันที่
4. กด "ทดลองพิมพ์เซียมซี" ดูหน้าตาจริงบนกระดาษ 203 dpi (ตัวไทย/จีนต้องชัดหลังแปลงขาวดำ threshold 160)
5. ตั้งไดรเวอร์ TM-T82III เป็น Paper Cut = No Cut → เปิด `enabled` → ทดสอบ: ขายปกติ, พิมพ์ซ้ำ, ปิดกะ, เปิดลิ้นชัก, ถอดสาย USB ระหว่างพิมพ์, ปิด POS Hero ทิ้งไว้ — ทุกกรณีใบเสร็จต้องถูกตัด
6. จดปริมาณกระดาษที่ใช้เพิ่มต่อวัน, ทดสอบสาขาเดียว 2–3 วัน แล้วค่อยติดตั้งสาขาที่สอง

## หมายเหตุสำหรับการทำงานต่อ
- **อย่ารัน `npx electron .` จาก source** (กฎของโปรเจกต์) ทดสอบเฉพาะส่วนที่แยกได้ด้วย node; ดูหน้าตาใบด้วยการเรนเดอร์ `slip.html` ใน Edge headless
- repo นี้คือ `xziramoon/pos-lan` (branch `main`) — อย่าสับสนกับ `pos-hero-catalog` / `pos-hero-nuea`
- Release: บัมพ์ `version` ใน `package.json` → commit/push → `GH_TOKEN=$(gh auth token) npx electron-builder --publish always` → **จะเหลือเป็น draft ต้อง** `gh release edit vX.Y.Z --draft=false --latest` ไม่งั้นอัปเดตอัตโนมัติไม่เห็น → ตรวจด้วย `gh release view`
- เขียนไฟล์ที่มีภาษาไทยด้วย Write tool (heredoc ใน Bash ไม่เสถียร); Python อ่านไฟล์เป็น cp874 ต้องใส่ `-X utf8`/`encoding="utf-8"`
- ถ้าจะเปลี่ยนข้อความเซียมซี แก้ที่ `fortune/fortunes.json` ไฟล์เดียว (ไม่มีสคริปต์แปลงข้อมูลแล้ว)
